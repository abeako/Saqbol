# Правила работы в репозитории Saqbol

## Структура зафиксирована
- Папки верхнего уровня: `docs/`, `research/`, `content/`, `app/`, `server/`. Других не создавать.
- Подпапки внутри них — только те, что описаны в README.md. Всё про исследование — только в `research/` (не в `docs/`). Новая подпапка = сначала ADR в `docs/decisions/` и согласие Сулеймана.
- Перед созданием файла проверь, нет ли уже подходящего. Лучше дополнить существующий файл, чем плодить новые.
- Временные файлы, черновики, скрипты для разовых задач в репо не коммитить.

## Куда что класть
| Что | Куда | Имя файла |
|---|---|---|
| Статья в списке литературы | `research/reading-list.md` | одна строка в таблице, со статусом |
| Разбор статьи | `research/papers/NN-автор-год/` | `summary.md` + `implications.md`, копия папки `_template/` |
| Итог интервью | `research/interviews/` | `I01.md`, `I02.md`… по шаблону `_template.md` |
| История пострадавшего из интернета | `research/cases/` | `C01.md`, `C02.md`… по шаблону `_template.md` |
| Данные квиза | `research/quiz-data/` | только агрегаты, `YYYY-MM-DD-summary.md` / `.csv` |
| Выводы исследования | `research/SYNTHESIS.md` | один файл, обновляется |
| Как ведём исследование | `research/README.md` | методика, уровни доказательств |
| Решение (стек, аудитория, фича) | `docs/decisions/` | `NNNN-короткое-название.md` |
| Требования, персоны, флоу | `docs/product/` | `PRD.md`, `personas.md`, `user-flows.md` |
| Материалы для конкурсов | `docs/pitch/` | `competitions.md`, питч, one-pager |
| Сценарий звонка | `content/scenarios/` | `NN-тип-мошенничества.md` |
| Короткий урок / подсказка | `content/lessons/` | `NN-тема.md` |
| Код приложения | `app/` | стандартная структура Expo, см. `app/README.md` |
| Серверный код | `server/` | см. `server/README.md` |

## Приватность (репозиторий публичный!)
- Никаких имён, телефонов, адресов, фото, голосовых записей реальных людей.
- Сырые записи и заметки интервью хранятся у Сулеймана (телефон / Google Drive), в репо — только анонимный итог.
- Никаких ключей API в коде: только через `.env` (в `.gitignore`) и секреты Supabase/EAS.
- PDF статей не коммитить — только ссылку и свой конспект.

## Процесс
- Работа идёт в ветках, изменения — через pull request; Claude сам открывает и мержит PR, когда Сулейман согласен.
- `docs/ROADMAP.md` — источник правды о статусе. Отмечать выполненные пункты там.
- Сулейман работает с Android-планшета без ПК: сборка через EAS (облако), проверка через Expo Go / внутренний трек Google Play. Не давать инструкций, требующих компьютера.
- Языки интерфейса и контента: казахский и русский (английский — для конкурсных материалов).
