# Research

## Структура

```
docs/research/
├─ README.md            ← этот файл: как мы работаем со статьями
├─ reading-list.md      ← все статьи и их статусы
├─ papers/              ← разбор каждой статьи в своей папке
│  ├─ _template/        ← шаблон: копировать для новой статьи
│  └─ NN-автор-год/
│     ├─ summary.md       ← что в статье: методы, цифры, ограничения
│     └─ implications.md  ← что это может значить для Saqbol (гипотезы)
└─ synthesis/           ← (создаём после прочтения всех главных статей)
```

## Правило: не делать выводов по первым статьям

Выводы по отдельной статье — это **гипотезы**, а не решения. Они лежат **только** в папке этой статьи и **не переносятся** в `docs/product/`, пока не прочитаны все главные статьи из `reading-list.md`.

Зачем: если переносить выводы в дизайн сразу, первые прочитанные статьи окажутся «сильнее» последующих только потому, что их прочитали раньше.

Когда главные статьи прочитаны, делаем **синтез** (`synthesis/`):
1. Сводим все гипотезы из всех `implications.md` в одну таблицу.
2. Для каждой гипотезы смотрим, какие статьи её **подтверждают**, какие **противоречат**, а какие **молчат**.
3. Оцениваем силу доказательств (уровень в шапке `summary.md`), а **не порядок чтения**.
4. Только после этого переносим решения в `docs/product/`.

## Уровни доказательств (для шапки summary.md)

- **A** — RCT / мета-анализ, большая выборка, наша тема (звонки, пожилые)
- **B** — RCT или хороший эксперимент, но тема или аудитория соседняя
- **C** — наблюдательное исследование, опрос, обзор
- **D** — мнения, гайдлайны, небольшие выборки
