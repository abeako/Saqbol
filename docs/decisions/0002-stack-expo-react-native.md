# 0002 — Стек: Expo (React Native) + Supabase

- **Дата:** 2026-11-21
- **Статус:** принято

## Решение
- Приложение: React Native через **Expo** (TypeScript), сборка в облаке через **EAS Build**
- Сервер: **Supabase** (база, авторизация, Edge Functions для AI-звонка)
- Голос: **ElevenLabs** (уже используется в Saqbol Quiz)
- Публикация: сначала только Google Play (Android)

## Почему
- Разработка ведётся без ПК: Expo позволяет собирать в облаке и проверять на планшете
- Supabase и ElevenLabs уже подключены и знакомы
- App Store — позже, когда будет бюджет на аккаунт
