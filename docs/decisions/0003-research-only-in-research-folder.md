# 0003 — Всё исследование — в `research/`, статьи — папкой на статью

- **Дата:** 2026-11-24
- **Статус:** принято

## Решение
- Материалы исследования лежат только в `research/`. Папки `docs/research/` нет.
- Список статей — `research/reading-list.md`.
- Разбор статьи — папка `research/papers/NN-автор-год/` с двумя файлами: `summary.md` (что в статье) и `implications.md` (гипотезы для Saqbol). Шаблон — `research/papers/_template/`.
- Синтез по статьям — раздел в `research/SYNTHESIS.md`, отдельной папки `synthesis/` нет.

## Почему
Два параллельных PR создали две папки исследования (`research/` и `docs/research/`) с разными шаблонами конспекта. Это путало, куда класть новые статьи. Формат «папка на статью» уже использовался в первом разборе (Robb & Wendel) и отделяет факты статьи от наших гипотез — это нужно для правила «не делать выводов по первым статьям».

## Последствия
- Старый плоский шаблон `research/papers/_template.md` удалён.
- `CLAUDE.md`, `README.md`, `research/README.md` обновлены.
