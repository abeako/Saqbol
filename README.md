# Saqbol

**Saqbol** (каз. «будь бдителен») — мобильное приложение, которое учит пожилых людей в Казахстане распознавать телефонных мошенников и правильно действовать: через безопасные тренировочные «звонки мошенника» на казахском и русском.

> Статус: старт проекта (ноябрь 2026). План — [docs/ROADMAP.md](docs/ROADMAP.md).

## Для кого
Люди 60+ и их взрослые дети/внуки, которые помогают им с телефоном. Подробнее — [docs/decisions/0001-target-audience-elderly.md](docs/decisions/0001-target-audience-elderly.md).

## Структура репозитория

```
Saqbol/
├── docs/            — всё, что описывает проект
│   ├── ROADMAP.md   — план и статус по неделям
│   ├── decisions/   — важные решения (ADR), по одному файлу на решение
│   ├── product/     — требования (PRD), персоны, сценарии пользователя, макеты
│   └── pitch/       — материалы для конкурсов: питч, видео, список конкурсов
├── research/        — исследование (как работаем — research/README.md)
│   ├── reading-list.md — список статей и статусы
│   ├── papers/      — разбор статей (1 папка = 1 статья: summary + implications)
│   ├── interviews/  — анонимные итоги интервью (без сырых записей!)
│   ├── cases/       — реальные истории пострадавших из интернета (ссылка + разбор)
│   ├── quiz-data/   — агрегированные результаты Saqbol Quiz
│   └── SYNTHESIS.md — главные выводы исследования
├── content/         — учебный контент, независимый от кода
│   ├── scenarios/   — сценарии мошеннических звонков (kk / ru)
│   └── lessons/     — короткие уроки и подсказки
├── app/             — мобильное приложение (Expo / React Native)
└── server/          — серверная часть для AI-звонка (Supabase Edge Functions)
```

Правила, куда что класть, — в [CLAUDE.md](CLAUDE.md). Новые папки верхнего уровня не добавляются без отдельного решения в `docs/decisions/`.
