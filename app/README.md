# Приложение (Expo / React Native)

Создаётся на этапе 3 (с 8 дек). Плановая структура:

```
app/
├── app/          — экраны (Expo Router)
├── src/
│   ├── components/
│   ├── features/   — calls, lessons, progress
│   ├── services/   — supabase, audio
│   ├── i18n/       — kk, ru
│   └── theme/      — крупные шрифты, цвета
└── assets/       — логотип, иконки, аудио
```
