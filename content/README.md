# Контент

Учебный контент отдельно от кода, чтобы его можно было читать и править без программирования.

- `scenarios/NN-тип.md` — сценарий звонка: схема, роль мошенника, шаги, красные флаги, правильные действия, тексты на ru и kk
- `lessons/` — короткие уроки и подсказки

Каждый сценарий должен ссылаться на источник в `research/` (кейс, интервью или статью).
